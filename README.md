# Battleship

A simple Battleship (Schiffe versenken) game against the computer, built with plain HTML, CSS and JavaScript.

## How to play

1. Download this repository (green **Code** button → **Download ZIP**) and unzip it, or `git clone` it.
2. Open `index.html` in any modern browser. No installation or server needed.
3. Click **Randomize Fleet** until you like your ship layout, then **Start Battle**.
4. Click cells in **Enemy Waters** to fire. Red = hit, light dot = miss. The computer fires back after every shot.
5. Sink all five enemy ships to win. Click **New Game** to restart at any time.

## Files

- `index.html` – page structure
- `style.css` – visual design
- `script.js` – game logic
